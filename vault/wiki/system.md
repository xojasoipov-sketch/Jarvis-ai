# Speak → Route → Remember → Repeat

1. **Speak** — voice or text in
2. **Route** — skill router picks the right SKILL.md
3. **Execute** — skill runs (metrics, plan, vault, …)
4. **Remember** — result lands in vault as markdown
5. **Repeat** — next turn uses vault context
